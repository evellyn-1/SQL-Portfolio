# Customers and Products Analysis Using SQL

## Kontext
Analyse der Verkaufsdatenbank eines Modellauto-Herstellers aus der Perspektive
einer Data Analystin. Ziel war es, mit SQL datenbasierte Antworten auf
Fragen zu Lagerbestand, Kundschaft und Marketing zu liefern.

## Verwendete SQL-Konzepte
- SELECT, WHERE, ORDER BY – gezieltes Filtern und Sortieren von Daten
- JOINs (INNER/LEFT) – Verknüpfung mehrerer Tabellen
- Subqueries – verschachtelte Abfragen für komplexere Fragestellungen
- Aggregatfunktionen (SUM, COUNT, AVG) mit GROUP BY

## Fragestellungen
- [z. B. Welche Produkte haben den geringsten Lagerbestand im Verhältnis zu den Verkäufen?]
- [z. B. Welche Kund:innen generieren den höchsten Umsatz?]
- [z. B. Welche Marketingmassnahmen könnten sich lohnen?]
